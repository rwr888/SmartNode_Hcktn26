# SmartNode Platform
## Architecture Document
**Version:** 0.3

---

# 1. Purpose

SmartNode Platform is a modular IoT platform designed to monitor industrial equipment by collecting, processing and analyzing operational data.

The platform has been designed to remain independent of the hardware source, allowing data to originate from simulators, ESP32 devices or future industrial controllers (PLC) without modifying the backend architecture.

---

# 2. Problem Statement

Small and medium-sized industries often lack predictive maintenance solutions because existing platforms are:

- Expensive
- Hardware dependent
- Difficult to scale
- Focused only on monitoring instead of operational intelligence

---

# 3. Proposed Solution

Develop a modular backend capable of:

- Receiving data from multiple sources.
- Evaluating machine health using engineering rules.
- Generating alerts automatically.
- Storing operational history.
- Providing a REST API for dashboards and future mobile applications.

# 5. Backend Modules
| Module    | Responsibility                       |
| --------- | ------------------------------------ |
| Health    | Service health verification          |
| Machines  | Sensor simulation and machine status |
| Database  | MongoDB connection and collections   |
| Rules     | Health evaluation engine             |
| Alerts    | Alert generation and management      |
| Dashboard | Future visualization layer           |
| Simulator | Virtual sensor source                |
| Firmware  | ESP32 firmware (future)              |

# 6. Database
machines

Stores the latest status of every monitored machine.

One document per machine.

alerts

Stores active and historical alerts generated by the Rules Engine.

Each alert contains:

machine_id
health
diagnostic
recommendation
acknowledged
timestamp
